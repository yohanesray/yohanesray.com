# yohanesray.com

Static site built with [Astro](https://astro.build/) and Tailwind CSS.

## Prerequisites

- [Bun](https://bun.sh/) v1.x

## Getting started

```bash
bun install
bun run dev
```

Dev server: [http://localhost:7331/](http://localhost:7331/)

## Production build

```bash
bun run build
bun run preview
```

Deploy the `dist/` directory to your host.
